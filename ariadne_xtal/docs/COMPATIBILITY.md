# SHELXT/SHELXL 兼容性与功能保留

Ariadne-Xtal 提供两种明确的执行方式。**原生模式**使用公开数学模型的独立实现；**官方后端模式**将原始文件交给用户已经安装的 SHELXT/SHELXL。选择模式是任务的一部分，不根据报错自动切换。

| 维度 | 原生模式 | 官方后端模式 |
|---|---|---|
| 数值实现 | 本项目的前向模型、P1 求解与约束精修 | 用户指定的官方可执行程序 |
| 指令语义 | 原生 JSON 配置；INS/RES 只允许明确结构子集 | 原始 INS/RES 及附属文件直接传递 |
| 完整 SHELXT 流程 | 未实现完整集成群判定与元素指认 | 由所安装 SHELXT 版本实施 |
| 完整 SHELXL 指令 | 未实施完整指令解释器 | 由所安装 SHELXL 版本实施 |
| 本交付验证 | 数学不变量、数值对照、模拟恢复、一个公开实测重精修案例 | mock 程序的文件与进程传输测试 |
| 官方二进制分发 | 无 | 无；用户自行安装 |

因此，“完整功能保留”在当前交付中的具体路径是**保留原始计算配方并显式调用官方后端**。这不是脱离官方程序的全功能独立替代品，也没有取得所有官方版本或所有指令组合的数值等价验证。

## 原生求解与精修的实际范围

原生初始求解实现已知晶胞组成的 P1 charge flipping 和稀疏原子投影。消光与等价反射诊断独立提供；它们没有组合成 SHELXT 的完整相位空间群判定流程。复杂无序、元素自动分类、一般孪晶解卷积与自动绝对构型判定不由该初始求解器实施。

原生精修覆盖坐标、正定 ADP、比例因子、显式占有率、完全重叠孪晶比例、精确相等/和约束及七类几何/ADP 限制。SHELXL 中有相似数学目的的指令，不代表其选择器、默认参数、约束传播、连通表、残基、收敛控制和输出细节已被逐项翻译。例如原生平面限制使用到拟合平面的距离，原生刚键限制使用一个方向性标量，两者分别不能直接视作完整 FLAT 或 RIGU。

## 文件处理原则

`ShelxDocument` 保留原始文本字节，支持词法识别、续行和活动指令审计。`document.write()` 写出原文。`document.to_structure()` 才进行有范围限制的数值转换，遇到未翻译指令会报出行号及指令名。保留文本不是执行指令。

`write_structure(model, "model.res")` 创建新的结构文件，不编辑原始精修配方。需要保留原始配方时使用 `ShelxDocument` 或官方后端路径。结构导出不自动附加看似熟悉但未在原生计算中实施的约束指令。

原生导入的关键约定：

- 特殊位置采用物理占有率，按位点重数与一般位置重数转换 SHELX SOF。
- 各向异性 U 转换为笛卡尔张量，导出时转换回标准晶体学 Uij。
- 缺少明确 DISP 时，导入警告原生异常散射项为零；可以主动提供色散项或调用异常散射计算接口。
- 单一 FVAR 初始比例只作明确记录与警告，原生精修重新估计比例；自由变量关联不被展开。
- 非零晶胞标准不确定度无法被原生精修传播，因此相应 ZERR 转换被拒绝。
- 原生 HKLF4 导入不实施隐含指标变换、反射筛选、合并或完整批次比例模型。
- CIF 导入得到结构模型，不重建其中嵌入的精修指令；显式对称操作优先于矛盾的群名。

### 条件子集

| 项目 | 本项目条件 |
|---|---|
| SFAC | 只接受中性元素名列表；自定义散射系数不被翻译 |
| HKLF | 只接受无其他参数的 `HKLF 4` |
| FVAR | 最多一个正的初始振幅比例值，且有重新估计比例的警告 |
| TEMP | 所有原子已经给出 U 时仅作元数据；温度相关默认 U 不被猜测 |
| ZERR | 晶胞不确定度全零时仅作元数据；非零值拒绝 |

对原子参数，当前转换支持整组坐标或整组 ADP 的固定标记。分量混合固定、引用其他自由变量、负 U riding 倍数等会拒绝原生转换。原生结构不以无提示的近似替代这些规则。

## 官方后端执行

启动时通过 `--shelxt` / `--shelxl` 或 Python 的 `legacy_executables` 指定绝对路径。任务再明确指定 `action="legacy"` 和 `engine`。不会搜索并执行一个偶然出现的同名程序，也不允许请求自行选择任意可执行路径。

每次运行建立独立子目录，复制原始 INS/RES、同名 HKL/FAB、项目树内嵌套 include 和明确附属文件。字节在复制前后核对，输入和输出保存哈希。include 的相对路径按进程工作目录解释，原始源文件不覆盖。路径越界、外部符号链接和循环 include 会被拒绝。

官方程序使用参数数组启动，`shell=False`。超时会终止进程组并记录日志。工作目录隔离不是 OS 安全沙箱；用户授权的外部程序仍持有运行账户的进程权限。

| 后端状态 | 含义 |
|---|---|
| `completed` | 进程退出码 0 |
| `process_failed` | 非零退出码 |
| `timed_out` | 超过配置的时间预算并被终止 |
| `start_failed` | 可执行程序启动失败 |

这些状态不包含结构化学结论。外部清单中的 `scientific_validation_performed` 为 `False`；agent 的 `scientific_acceptance` 为 `not_assessed`。原生 `fit.success` 也仅表示数值求解终止条件满足。

## 当前证据能支持的结论

原生结构因子通过独立 Gemmi 数值对照及物理不变量测试。模拟案例检验参数恢复、特殊位置、各向异性 ADP、孪晶、留出分组、秩亏诊断和相位候选进入精修的流程。公开 FeN₄ 案例用 71 个真实测量 F²，从发表模型及一个扰动初值进行局部重精修，结果与存档显示的 R 值精度一致。

该实测案例没有运行官方可执行文件，也没有原始探测器图像。它不能外推为从头求解成功率、普遍性能优势或全部指令组合等价。官方桥接的测试使用名称和注释明确标识的 mock executable，验证文件、参数、超时和错误状态传递。

## 核查与扩展

对某项复杂结构，先保留完整源文件并查看 `ShelxDocument.audit()`。如果要求沿用已有约束、残基、氢原子模型、非完全重叠孪晶或归档规则，选择官方后端。若改为原生数学模型，应把所需约束和限制明确写入 JSON，并保留该模型变更的任务记录。

新增一种原生指令翻译，应同时更新解析器、模型转换、数值实现、独立验证和本矩阵。只有保留文本或拥有名称相似的函数，不构成该指令的科学实现。
